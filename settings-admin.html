สถาปัตยกรรมความปลอดภัยป้องกันแอดมินขโมยข้อมูล (Admin Zero-Trust Defense)
1. ไม่เก็บ Master Secret บน Browser

ใช้ Unsigned Upload Preset สำหรับ Cloudinary และคีย์สาธารณะ (Anon Key / Google Client ID) เท่านั้น แม้แอดมินคนอื่นจะเปิด F12 Inspect ดูก็จะไม่ได้สิทธิ์ลบหรือขโมยโปรเจกต์

2. Cloudflare Worker Secure Proxy

ซ่อน Token และส่งคำขอผ่าน worker.js โดยเก็บ Secret Key ไว้ใน Environment Secrets ของ Cloudflare แอดมินทั่วไปไม่สามารถมองเห็นได้

3. Row Level Security (RLS)

ฐานข้อมูล Supabase ถูกป้องกันด้วย RLS บังคับให้นักศึกษาแก้ไขได้เฉพาะสิทธิ์ของตนเอง และห้ามลบตารางหลักโดยไม่ผ่านสิทธิ์ Super Admin

4. บันทึก Audit Log ถาวร (admin_logs)

ทุกครั้งที่มีการเปลี่ยนการตั้งค่าหรือปรับสิทธิ์ ระบบจะบันทึกอีเมลแอดมินผู้กระทำและเวลาลงตาราง admin_logs อัตโนมัติ ป้องกันการแอบเปลี่ยนโดยไร้ร่องรอย
